# 01 项目启动说明

## 1. 项目名称
校园活动报名与签到管理系统

## 2. 项目目标
本项目开发校园活动报名与签到管理系统，围绕活动发布、学生报名、签到统计三大核心业务构建完整线上管理流程，具体项目目标如下：
- 支持管理员完成校园活动信息发布、活动内容维护、报名人数上限配置及活动状态管理。
- 支持学生浏览活动列表、查看活动详情、在线提交报名申请，并可自主查询个人报名结果。
- 支持管理员进行报名名单审核、现场二维码签到核验、签到状态记录管理。
- 支持对活动报名数据、签到数据进行自动汇总统计，并提供统计结果导出功能，满足活动复盘与数据归档需求。

## 4. 项目边界
### 4.1 纳入范围
1. 项目管理类交付物：项目仓库搭建、团队角色分工、WBS范围计划、简化进度计划、配置管理规范等全套过程文档。
2. 需求与设计类交付物：系统需求调研、需求规格说明、系统架构设计、数据库设计、接口设计及页面界面原型。
3. 核心业务功能：活动管理模块、报名管理模块、签到管理模块、统计与导出模块的代码开发与功能实现。
4. 测试与验收类交付物：单元测试、集成测试、系统测试相关文档代码，以及项目功能验收记录与问题说明文档。
5. 使用说明文档：学生端、管理员端、签到管理人员端对应的操作说明文档。

### 4.2 不纳入范围
1. 不接入学校统一身份认证平台，不实现校园官方账号单点登录与学籍信息自动同步。
2. 不开发移动端独立APP，仅实现适配浏览器的Web端功能，无原生客户端开发任务。
3. 不涉及在线支付、缴费、退款等资金交易相关业务功能。
4. 不做高并发、高可用性能专项优化，不提供生产服务器部署运维及域名备案等上线配套服务。
5. 不支持复杂多级活动、多时段分批次报名、跨学院权限分级管理等扩展复杂业务规则。
